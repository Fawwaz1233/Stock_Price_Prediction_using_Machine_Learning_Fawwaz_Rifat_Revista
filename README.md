# Stock Price Prediction using Machine Learning

Proyek ini membangun model *machine learning* untuk memprediksi harga saham dan tren finansial menggunakan data historis. Terdapat dua studi kasus: prediksi data finansial umum dan prediksi untuk sektor food & beverage (F&B).

## Isi Repository
- `financial_model.ipynb` — notebook pelatihan model prediksi harga saham/data finansial.
- `financial_model_inf.ipynb` — notebook inference/prediksi menggunakan model yang telah dilatih.
- `fnb_model.ipynb` — notebook pelatihan model khusus data F&B.
- `fnb_model_inf.ipynb` — notebook inference untuk model F&B.
- `clean_financial_data.csv` — dataset finansial yang telah dibersihkan.
- `clean_fnb_data.csv` — dataset F&B yang telah dibersihkan.

## Cara Menjalankan
1. Clone repository ini.
2. Buka notebook yang diinginkan (`financial_model.ipynb` atau `fnb_model.ipynb`) menggunakan Jupyter Notebook/JupyterLab.
3. Jalankan seluruh sel secara berurutan untuk melihat proses pembersihan data, pelatihan model, dan evaluasi.
4. Gunakan notebook `*_inf.ipynb` untuk melakukan prediksi pada data baru.
